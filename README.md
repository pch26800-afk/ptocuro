# Procuro Group — site vitrine

Site statique (HTML/CSS/JS), déployable tel quel sur Vercel.

- **Coordonnées et délai de réponse** : à renseigner dans `js/config.js` (seul fichier à modifier).
- **Formulaire de devis** : envoyé par e-mail via [Web3Forms](https://web3forms.com) (clé d'accès dans `js/config.js`).
- **Mentions légales** : compléter les champs entre crochets dans `mentions-legales.html`.

## Déploiement Vercel
Add New → Project → importer ce dépôt → Framework Preset : *Other*, pas de commande de build → Deploy.
